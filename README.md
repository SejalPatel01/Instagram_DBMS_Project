# Instagram DBMS Project

A comprehensive Database Management System (DBMS) project designed for an Instagram-like social media platform that supports user interaction, content sharing, messaging, reels, stories, and social networking features.

---

# 📚 Project Overview

This project is developed to simulate the database architecture of a modern social media platform similar to Instagram.

The main objective of this project is to design a scalable and normalized relational database system capable of handling:

* User management
* Posts and media sharing
* Followers and social connections
* Comments and likes
* Stories and highlights
* Reels and music integration
* Chats and messaging
* Calls and communication

---

# 🎯 Objectives

The primary objectives of this project are:

* To understand real-world database design
* To implement ER modeling concepts
* To design a fully normalized relational schema
* To apply BCNF normalization practically
* To manage complex relationships between entities
* To write meaningful SQL queries for real-world scenarios
